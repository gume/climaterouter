# ClimateRouter integration package

This directory is reserved for the Home Assistant custom integration. The implementation starts in milestone M1 of
[`docs/PLAN.md`](../../docs/PLAN.md).

Planned contents: `manifest.json`, `__init__.py`, `config_flow.py`, `coordinator.py`, `router.py`, `models.py`,
`climate.py`, `binary_sensor.py`, `sensor.py`, `button.py`, `select.py`, `services.py`, `diagnostics.py`,
`services.yaml`, `strings.json`, `icons.json`, and `translations/en.json`.
